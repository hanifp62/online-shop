## Warnings (should fix)

1. **MEDIUM — Prototype mobile language switch leaves nearby interface in Indonesian.** `prototype/index.html:1126-1130,1147-1159`: the new four-language drawer translates its links and `lang_selector`, but its dialog label, heading, currency label, and currency description have no `data-i18n`. The supplied `shots-sweep-4/prototype-fr-mobile.png` visibly displays French links and `LANGUE` alongside `Navigasi Kriya`, `MATA UANG`, and `Seluruh harga ditampilkan dalam IDR (Rp).` This contradicts `completion-frontend/RESULT.md`'s broad translation-quality PASS for the same interaction. Add keys in all four prototype dictionaries and translation attributes for these strings; assert resulting visible text after switching, rather than only `document.lang` and localStorage. `tests/prototype-mobile-lang.test.mjs:9-27` checks only markup/delegation and CSS. `completion-frontend/sweep.mjs:35-48` collects translated text but only fails on status, language metadata, overflow, runtime errors, and persistence.

2. **MEDIUM — Dual-guard logout rotation has no old-session replay proof.** `app/Http/Controllers/AuthController.php:84-95`, `app/Http/Controllers/AdminAuthController.php:36-47`, `tests/Feature/RescueBackendAuditTest.php:193-242`: both controllers now call `migrate(true)` and regenerate CSRF token when the other guard remains authenticated. This addresses the earlier security finding at source level; Laravel `Store::migrate(true)` destroys the current session ID and generates a new one (`vendor/laravel/framework/src/Illuminate/Session/Store.php:631-643`). Tests assert ID/token change and remaining guard preservation, but do not replay the old browser session cookie to prove it cannot access the retained guard under the configured session driver. Add isolated HTTP integration replay test with persistent test session storage before closing this security claim. Do not invalidate the shared session: that would log out the other guard. The prior `completion-review/SECURITY_REVIEW.md` finding is **partially addressed**, not copied as an unfixed code defect.

3. **MEDIUM — Auxiliary touch targets remain below 44×44px.** `prototype/app.css:3330-3345` correctly sizes the new language buttons, but `completion-frontend/RESULT.md:17-23` explicitly records undersized category pills, quantity controls, and editorial anchors. Apply target-size fixes or documented spacing exceptions to the actual reported controls and retest affected mobile views. This is a known WCAG 2.2 usability gap, not a 56-case sweep failure: the sweep collects `smallTargets` but does not fail on them (`completion-frontend/sweep.mjs:25-48`).
