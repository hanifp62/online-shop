## Temuan blocker dan patch sementara

Run `085118576Z` tanpa patch berhenti di S1: UI melaporkan seluruh field alamat wajib kosong. Penyebab: `action()` menonaktifkan input sebelum handler membaca `FormData`; FormData mengabaikan input disabled. Patch sementara membaca FormData lebih awal, lalu run `085153769Z` lulus S1–S5. Karena `resources/views` di luar ownership tugas ini, patch sudah dibatalkan dan diff file view kosong. Bukti run eksperimen tetap dipertahankan, tetapi tidak dapat dipakai untuk klaim PASS kode saat ini.

Ditambahkan capability `provision` terbatas untuk root fixture bersih, plus `tests/python/test_amadis_provision.py`, dan harness browser `scripts/amadis/browser-lifecycle.cjs`.
