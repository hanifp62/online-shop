### Ringkasan Parameter Google Stitch
- **Atmosphere:** Luxury Art Gallery Airy (Density: 3/10, Variance: 7/10, Motion: 6/10)
- **Primary Canvas:** Linen Ivory (`#F3EFE7`)
- **Accent:** Champagne Gold (`#B69A64`, Saturation 42%)
- **Typography:** Bodoni Moda (Display) + Manrope (Body/UI) + JetBrains Mono (Data/Admin)
- **Anti-patterns Banned:** Emojis, Inter font, pure black, neon purple glows, generic 3-column rows.
- **Screen Prompts:** Tersedia untuk Storefront, Detail Produk, Cart Drawer, dan Atelier Admin Workspace.
